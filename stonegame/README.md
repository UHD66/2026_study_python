# STONE_TAKING_GAME!
* I created a STONE TAKING GAME by python.
## reason for production
* To learn the basics of python(Loop processing, branching logic, and exception handling)
* Learn how to use the random module.
## Key points!
* You can play against the cpu!
* You can choose the number of stoens.
* I've color-coded the text to make the number of stones and other details easier to understand!
## Future goals
* I will make it possible to choose whether to go first or second.
* I will prevent the first and second player roles from switching unexpectedly.
## How to play
1. Open this script in google colaboratory.
2. Click the Run button to start the game.
3. Guess the secret number by entering your inputs in the console!
